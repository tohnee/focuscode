# FocusCode v0.4 Beta2 与 Pi Coding Agent 能力对标分析

报告日期：2026-07-21  
FocusCode 版本：`0.4.0-beta.2`  
Pi 取证基线：官网 pi.dev + `@earendil-works/pi-coding-agent@0.80.10`

---

## 1. 结论先行

### 1.1 核心定位差异

| 维度     | FocusCode                     | Pi                                   |
| -------- | ----------------------------- | ------------------------------------ |
| 设计哲学 | 强契约 + 双路径 + Policy 收口 | Primitives, not features——极简可扩展 |
| 目标用户 | 企业级部署 + 高合规场景       | 个人开发者 + 工作流自定义            |
| 核心价值 | 可审计、可重放、策略可控      | 灵活适配、生态丰富、上手快           |

### 1.2 能力差距概览

**FocusCode 优势（Pi 不具备或弱）**：

- 企业级 fail-closed 默认值（Provider/model/extension/media/sandbox allowlist）
- Effect Spine 审计主链 + HMAC 链式审计
- 四类内置沙箱（Host/Docker/gVisor/SSH VM）+ digest pin + pull-never
- Atomic Decision 强制规范 + ModelPack binding 防漂移
- PolicyEngine 单源规则 + 两路径等价验证
- 崩溃恢复三窗口语义（窗口 B/C 已实现）
- AES-256-GCM 加密凭据库 + OAuth PKCE/device/refresh/revoke
- 协议映射已落地 ACP/MCP/A2A/Native Capsule

**Pi 优势（FocusCode 缺失或弱）**：

- 15+ Provider 目录（含 Ollama/OpenRouter/Groq/Cerebras/xAI/Bedrock/Azure）
- 中途切换模型（`/model`、`Ctrl+L`、`Ctrl+P`）
- 扩展 API 深度（拦截/改写/持久状态/自定义 UI）
- 50+ 官方扩展示例 + npm/git 包分发
- 终端编辑器深度（selection/IME/hardware cursor）
- 结构化 compaction + branch summary
- 社区活跃度 + 真实集成案例（OpenClaw）
- 会话树交互（label/clone/branch summary）
- 拖入多模态

## 2. 详细差距分析

### 4.2 技术方案要点

#### 4.2.1 Provider 扩展

新增 Provider 遵循现有 `ModelProfile` 模式：

```typescript
models: {
  "ollama/llama3": {
    contextWindow: 8192,
    maxOutputTokens: 4096,
    capabilities: { input: ["text"], toolCalling: true },
    compatibility: { thinkingFormat: "none" },
    reliability: { timeoutMs: 60000, maxRetries: 1 }
  },
  "openrouter/meta-llama-3.1-70b": {
    contextWindow: 128000,
    maxOutputTokens: 16384,
    capabilities: { input: ["text", "image"], toolCalling: true },
    compatibility: { thinkingFormat: "openai" },
    reliability: { timeoutMs: 120000, maxRetries: 2 }
  }
}
```

#### 4.2.2 中途模型切换

在 `CodingAgent` 中新增 `switchModel(model: ModelSpec)` 方法：

```typescript
async switchModel(model: ModelSpec): Promise<void> {
  await this.modelClient.close();
  this.modelClient = await createModelClient(model, this.config);
  this.config.model = model;
  this.emit('model_changed', model);
}
```

TUI 层监听事件并刷新状态栏。

#### 4.2.3 结构化 Compaction

在 `SessionStore` 中实现主题感知压缩：

```typescript
interface CompactionStrategy {
  compact(events: SessionEvent[], maxChars: number): SessionEvent[];
}

class TopicBasedCompaction implements CompactionStrategy {
  compact(events: SessionEvent[], maxChars: number): SessionEvent[] {
    const topics = clusterByTopic(events);
    return topics.map((topic) => summarizeTopic(topic));
  }
}
```

#### 4.2.4 扩展 API 深化

扩展 `ExtensionHostLike` 接口：

```typescript
interface ExtensionHostLike {
  onBeforeToolCall?: (intent: ToolIntent) => ToolIntent | Promise<ToolIntent>;
  onAfterToolCall?: (result: ToolResult) => ToolResult | Promise<ToolResult>;
  getState<T>(key: string): T | undefined;
  setState<T>(key: string, value: T): void;
}
```

### 4.3 风险与依赖

| 风险                  | 说明                                         | 缓解措施                      |
| --------------------- | -------------------------------------------- | ----------------------------- |
| Provider API 变化     | 新增 Provider 可能频繁变更                   | 声明式 Profile + revision pin |
| 中途切换模型状态丢失  | 切换模型可能导致 reasoning continuation 丢失 | 保存并迁移 continuation state |
| Compaction 质量不稳定 | 自动压缩可能丢失关键信息                     | 可配置策略 + 用户审核         |
| 扩展 API 兼容性       | 新增 API 可能破坏现有扩展                    | 向后兼容设计                  |

### 4.4 验收标准

| 里程碑        | 验收标准                                                             |
| ------------- | -------------------------------------------------------------------- |
| Provider 广度 | 新增 8+ Provider，每 Provider 至少通过 text/tool 协议测试            |
| 中途切换      | `/model` 命令在 TUI/interactive/RPC 模式下均可工作，切换后上下文保留 |
| 编辑器深化    | selection/IME/高亮在 macOS/Linux 终端均可正常工作                    |
| Compaction    | 长会话（100+ turns）自动压缩后关键信息不丢失                         |
| 扩展 API      | 5+ 官方扩展示例使用新 API 编译通过                                   |
