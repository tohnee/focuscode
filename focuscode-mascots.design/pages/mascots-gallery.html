设计原则

身份一致
图标 / 名字 / 标签 / 口吻 / 称号来自同一档案，切换伙伴时全局同步，不会出现身份错乱。
反馈有因
思考 / 执行 / 成功 / 失败 / 压缩 / 完成 / 升级分别触发专属口吻，情绪点与状态一一对应。
可爱但克制
短句最多 4 行；专注布局（如 Zen 模式）自动隐藏角色形象，不干扰深度编码。
成长可见
等级改变角色帧、配色光晕与阶段称号，每段羁绊（4 段 ◆/◇）都有明确的解锁反馈。
向后兼容
persona 字段可选，旧 JSON 配置安全回退到默认 Foxy，不会破坏已有会话与配置。
零运行时依赖
复用现有终端渲染器，伙伴信息只是数据（JSON），不需要额外的图片、字体或运行时。
