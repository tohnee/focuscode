# FocusCode Evaluation Layout

The Alpha ships deterministic protocol/security tests under package test directories. This folder is
reserved for evidence-bearing task sets that should remain separate from unit tests:

- `protocol/`: recorded stream/finish/tool/reasoning fixtures per Model Pack;
- `security/`: prompt injection, path, egress, secret, MCP rug-pull and A2A confused-deputy cases;
- `real-tasks/`: base revision, environment, objective, allowed scope, verifier and Owner outcome.

Do not add benchmark labels generated by the same model being evaluated. Every real task should pin
model, Pack, Harness, deployment, policy, tool registry and budget digests so Model × Harness
factorial comparisons remain attributable.
