# Generic OpenAI-compatible Model Pack

This Alpha pack uses a canonical JSON `ModelDecision` carried in assistant content. It is a
transport baseline, not a claim that all OpenAI-compatible endpoints share the same tool or
reasoning semantics.

Before granting a model `change` certification, create a model-family Pack and run protocol,
atomic-parser, edit, security and real-task conformance suites. The development certificate
emitted by the local SDK is explicitly `sandbox-only`.
